# 真实花材库 + 颜色映射

花朵必须真实存在。下表按“颜色”组织，方便把专辑配色快速映射到真实花材。

## 按颜色查花材

### 黑色 / 炭黑 / 深灰（暗调压重）

- 黑马蹄莲（深紫近黑）

- 深色银莲花（花心近黑）
- 深色菊（深紫/深咖调）

## 喷漆 / 染色改色（强推，可让整体更一致）

参考真实项目常用手法：当封面是极冷感/暗调/金属色时，用喷漆或染色把普通花材改成封面同色，使整束更统一、更高级。可喷漆/染色的常见花材：

- **喷银**：红掌（银掌）、玫瑰、郁金香、花烛 —— 冷调/金属封面
- **喷黑/哑光黑**：蝴蝶兰、玫瑰、洋桔梗、绣球 —— 暗调哥特封面
- **染色蓝**：玫瑰、绣球、满天星 —— 清冷蓝封面
- **喷彩色**：按封面主色喷白掌、白玫瑰、马蹄莲
- **喷金/银**：叶材、草材（尤加利、喷泉草、蒲苇）—— 金属质感点缀

> 效果图 prompt 用 `spray-painted` / `dyed` 描述；文字设计稿里标注“喷漆/染色处理”。这是实现“整体颜色统一”的关键手法。

## 映射原则

1. 封面主色 → 主包装纸 + 主花材基底色
2. 封面过渡色 → 绣球/满天星等块状填充，营造渐变层次
3. 封面点睛色 → 1–2 支高辨识度焦点花 + 缎带颜色
4. 暗调封面 → 用小面积白/银提亮，避免整束沉闷
5. 撞色封面 → 花材也走撞色，不必强求单一色系
6. **克制花材（可实际制作）**：每次只选 3–5 种主花/配花 + 1–2 种叶材，疏密有致、花店可真实制作；不要堆砌超过 6–7 种。
7. **颜色统一优先用喷漆/染色**：当自然花材颜色无法精准匹配封面时，优先喷漆/染色改色，而非增加更多花色。

> 若需染色花（蓝玫瑰、喷银红掌、哑光黑蝴蝶兰等），在方案中明确标注“染色/喷漆处理”，效果图 prompt 中写 `dyed` / `spray-painted`。
