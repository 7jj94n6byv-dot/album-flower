# 参考范例（从真实项目拆解）

以下范例展示了“专辑封面 → 花束”如何对应。均为真实存在的花材与包装，可直接作为风格模板参考。

## 范例 1：黄黑红高对比复古（陶喆《I'm OK》）

- **封面**：黄底半调点阵人像 + 红色手写“I'm ok” + 银字署名
- **配色**：主色黑 + 亮黄；点睛正红；细节白
- **花材**：黑马蹄莲（珍珠点缀）、黑玫瑰、黑系肌理花；黄马蹄莲、黄填充叶；正红绒状小花；白瓣黑点黄心小装饰花
- **包装**：纯黑外层纸 + 亮黄底黑波点内衬 + 亮黄缎带
- **风格**：高对比、复古波普

## 范例 2：冷蓝系清冷（周兴哲《小时候的我们》）

- **封面**：深蓝渐变，竖排英文署名
- **配色**：藏蓝主色 + 冰蓝/雾霾蓝过渡 + 白/银提亮
- **花材**：渐变蓝绣球、浅蓝玫瑰、蓝紫飞燕草、浅蓝兔尾草、银蓝芒草、白雾中情人、奶白装饰叶
- **包装**：深蓝包装纸 + 银白网纱 + 浅蓝银双丝带；复刻封面竖排文字
- **风格**：清冷沉静、同色系渐变

## 范例 3：银黑白冷感（周兴哲《Almost》）

- **封面**：黑白灰调
- **配色**：炭黑/深哑灰主色 + 银提亮
- **花材**：喷色黑蝴蝶兰、喷银郁金香、喷银红掌、喷黑洋桔梗、银喷泉草、银叶菊
- **包装**：深灰艺术纸 + 银灰雪梨纸 + 炭黑欧雅纸折叠尖角 + 银灰缎带
- **风格**：清冷疏离、哑光 vs 金属光泽对比

## 范例 4：暗黑哥特（说唱专辑）

- **配色**：纯黑 + 血红 + 米白点睛
- **花材**：手绘红掌、黑骑士玫瑰、暗酒红芍药、红龙须草、红彼岸花、黑羽毛、米白风车果
- **包装**：黑色哑光卡纸尖角 + 黑拉丝纱 + 红棕晕染肌理纸 + 黑哑光丝带
- **风格**：血腥哥特、强对比

## 范例 5：波普撞色（Madvillainy 九格封面）

- **配色**：高饱和明黄/橙/红/桃粉/宝蓝/湖蓝/草绿/紫全撞色
- **花材**：黄红掌、红百合、蓝紫大丽花、粉白小菊、黄绣球、蒲苇、羽毛状配草
- **包装**：多色平面纸不规则叠放 + 桃粉/湖绿握柄 + 淡黄绿丝带
- **风格**：复古彩色版画、活泼撞色

## 范例 6：暗黑新中式（易烊千玺《魑魅魍魉》）

- **配色**：低饱和酒红 + 炭黑 + 灰褐
- **花材**：酒红丝绒玫瑰、酒红掌、做旧红百合、酒红绣球、炭黑松针、黑干玫瑰、枯树枝
- **包装**：做旧水墨杜邦纸撕毛边 + 黑/酒红细棉绳 + 主题拍立得卡
- **风格**：颓诡国风、蒙尘做旧

## 通用设计套路

1. 纯色/暗调封面 → 花材与包装走同色系深浅 + 少量跳色点睛
2. 撞色/波普封面 → 花材直接撞色，包装多层多色
3. 封面有标志性文字 → 用背板卡纸复刻排版（图里不还原文字，只做文字贴片或吊牌提示）
4. 封面有质感（半调/颗粒/金属）→ 包装纸材质呼应（铝箔/网纱/肌理纸）
