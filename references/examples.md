# 参考范例（从真实项目拆解）

以下范例展示了“专辑封面 → 花束”如何对应。均为真实存在的花材与包装，可直接作为风格模板参考。

## 成品视觉案例

### Taylor Swift《Lover》：粉蓝柔雾

![Lover 粉蓝专辑花束](../assets/examples/case-01-lover.jpg)

- **配色**：大面积柔粉，浅蓝与银灰过渡，玫红缎带点睛
- **花材结构**：粉玫瑰、粉色洋桔梗、粉色洋牡丹，以浅蓝飞燕草拉高轮廓，银叶菊压低底部
- **包装对应**：粉色主体包装叠一层浅蓝内衬，包装正面保留封面手写感标题
- **可复用经验**：柔和封面也需要高低结构；用线条花拉开空气感，不把同色花材堆成圆球

### TWS《Sparkling Blue》：清透蓝白

![Sparkling Blue 蓝白专辑花束](../assets/examples/case-02-tws-sparkling-blue.jpg)

- **配色**：白色为底，宝蓝与雾蓝为主体，灰绿色叶材缓和冷感
- **花材结构**：蓝绣球作为视觉重心，蓝白玫瑰与蓝飞燕草形成前后和高低层次，尤加利延伸轮廓
- **包装对应**：白色硬挺包装叠宝蓝色块，正面标题沿用封面的粗圆字形与蓝色
- **可复用经验**：同色系不等于单调；通过花型尺寸、明度和包装切面建立层次

### TWS《Summer Beat!》：夏日撞色

![Summer Beat 多彩专辑花束](../assets/examples/case-03-tws-summer-beat.jpg)

- **配色**：蓝、黄、粉、橙、绿共同出现，以白色包装统一多色焦点
- **花材结构**：蓝绣球作为中心锚点，黄玫瑰、粉玫瑰、橙郁金香、紫大丽花与粉蝴蝶兰对应封面色块
- **包装对应**：白色外层搭配绿色内衬和黄色缎带，背板延续封面的彩色拼字
- **可复用经验**：仅当封面本身明确采用多色撞色时突破 2–3 色限制；仍要用一个大面积中性色收束画面

## 范例 1：黄黑红高对比复古（陶喆《I'm OK》）

- **封面**：黄底半调点阵人像 + 红色手写“I'm ok” + 银字署名
- **配色**：主色黑 + 亮黄；点睛正红；细节白
- **花材**：黑马蹄莲（珍珠点缀）、黑玫瑰、黑系肌理花；黄马蹄莲、黄填充叶；正红绒状小花；白瓣黑点黄心小装饰花
- **包装**：纯黑外层纸 + 亮黄底黑波点内衬 + 亮黄缎带
- **风格**：高对比、复古波普

## 范例 2：冷蓝系清冷（周兴哲《小时候的我们》）

- **封面**：深蓝渐变，竖排英文署名
- **配色**：藏蓝主色 + 冰蓝/雾霾蓝过渡 + 白/银提亮
- **花材**：渐变蓝绣球、浅蓝玫瑰、蓝紫飞燕草、浅蓝兔尾草、银蓝芒草、白雾中情人、奶白装饰叶
- **包装**：深蓝包装纸 + 银白网纱 + 浅蓝银双丝带；复刻封面竖排文字
- **风格**：清冷沉静、同色系渐变

## 范例 3：银黑白冷感（周兴哲《Almost》）

- **封面**：黑白灰调
- **配色**：炭黑/深哑灰主色 + 银提亮
- **花材**：喷色黑蝴蝶兰、喷银郁金香、喷银红掌、喷黑洋桔梗、银喷泉草、银叶菊
- **包装**：深灰艺术纸 + 银灰雪梨纸 + 炭黑欧雅纸折叠尖角 + 银灰缎带
- **风格**：清冷疏离、哑光 vs 金属光泽对比

## 范例 4：暗黑哥特（说唱专辑）

- **配色**：纯黑 + 血红 + 米白点睛
- **花材**：手绘红掌、黑骑士玫瑰、暗酒红芍药、红龙须草、红彼岸花、黑羽毛、米白风车果
- **包装**：黑色哑光卡纸尖角 + 黑拉丝纱 + 红棕晕染肌理纸 + 黑哑光丝带
- **风格**：血腥哥特、强对比

## 范例 5：波普撞色（Madvillainy 九格封面）

- **配色**：高饱和明黄/橙/红/桃粉/宝蓝/湖蓝/草绿/紫全撞色
- **花材**：黄红掌、红百合、蓝紫大丽花、粉白小菊、黄绣球、蒲苇、羽毛状配草
- **包装**：多色平面纸不规则叠放 + 桃粉/湖绿握柄 + 淡黄绿丝带
- **风格**：复古彩色版画、活泼撞色

## 范例 6：暗黑新中式（易烊千玺《魑魅魍魉》）

- **配色**：低饱和酒红 + 炭黑 + 灰褐
- **花材**：酒红丝绒玫瑰、酒红掌、做旧红百合、酒红绣球、炭黑松针、黑干玫瑰、枯树枝
- **包装**：做旧水墨杜邦纸撕毛边 + 黑/酒红细棉绳 + 主题拍立得卡
- **风格**：颓诡国风、蒙尘做旧

## 通用设计套路

1. 纯色/暗调封面 → 花材与包装走同色系深浅 + 少量跳色点睛
2. 撞色/波普封面 → 花材直接撞色，包装多层多色
3. 封面有标志性文字 → 用背板卡纸复刻排版（图里不还原文字，只做文字贴片或吊牌提示）
4. 封面有质感（半调/颗粒/金属）→ 包装纸材质呼应（铝箔/网纱/肌理纸）
